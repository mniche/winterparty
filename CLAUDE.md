# kids' game hackathon

- Games are built for and with ~9-year-olds; they make the creative calls.
- Keep each game a single self-contained index.html (inline CSS/JS, no libraries, no network, no image files; emoji or canvas shapes).
- Must run via `open index.html`.
- Keep tunable values in a CONFIG object at the top of the script.
- Make one small change per request, then stop and say how to test it.
- Prefer working and simple over impressive. Never break the start → play → game over → play again loop.
- Don't add anything that collects names or personal info.
